# 游戏人生 · 像素名人人生模拟（MVP）

纯静态网页游戏：HTML5 Canvas + 原生 JS，无构建、无外部 CDN、无外部美术素材（像素画全部由代码生成）。
打开 `index.html` 即可玩，也可以把整个文件夹传到任意静态托管（GitHub Pages、Netlify、Vercel、OSS、COS 等）。

## 玩法
- 8 位可玩名人（全部为戏仿名）：马斯可、黄仁训、比尔·盖兹、川普朗、马芸、贝克汉、欧巴码、孙正一，每人 3 个开局年代。
- 屏幕上方始终是本章目标，金色箭头和小地图（绿点是你，黄点是目标）会带路。WASD 或点击地面移动，靠近后按 E，或直接点目标。
- 对话用「继续」或回车推进。数字键只选中，不直接生效。章节选择、卖公司、买车、飞去别的城市都要再确认一次。第一次进入会有三段新手引导。
- C 上下车，T 时间线，M 静音，N 昼夜；手机有方向键和 A 键。投资、社交、买车、坐船是可选支线。
- 城市里：家（休息/存档/结局）、公司总部（开会、融资、卖公司、新项目）、投资大厅、机场（飞 13 个城市，可买私人飞机）、
  车行、俱乐部、咖啡馆（八卦/提示）、研发园区、码头（邀朋友坐邮轮）。
  - 运动员模式（贝克汉）：总部变成「训练基地」（加练、比赛、球迷见面会），研发园区变成「康复中心」，投资大厅多了「代言谈判」。
  - 政治人物模式（欧巴码）：总部变成「竞选办公室」（拉票演讲、筹款晚宴、走访社区），研发园区变成「政策智库」。
- 街头路人可以搭讪/聊天；特定城市+年份会出现 ★ 关键人物（只用资料里出现过的人物，戏仿名）。
- 每个资料节点是一章：先走到标记或去见资料里出现过的人物，读完短对话，再在章末选 📜 史实选择或 🔀 游戏备选（虚构）。选了游戏备选，后续依赖这一步的节点可能不再发生。章末有结算，并对照资料。
- 每个节点都有「📚 史实依据」：年份/月份、当时年龄、地点、资料置信度和来源数量（链接不在游戏内显示，见项目外的 SOURCES.md）。
- 时间线（T）随时对比“历史上的他 vs 你的他”，2026 年底进入结局结算。

## 史实节点从哪里来
- 节点里的年份、年龄、地点、事件、真实选择和数据，只取自项目外的研究资料（每人一份 JSON + MD）；
  “游戏备选”取自资料里列出的其他可能，明确标为虚构。置信度为“待核实”的条目要么跳过，要么用“据他本人说……”“约在……年间”等模糊表述。
- 政治人物只写选举、任职、法案与法院裁决，不涉及争议指控；各资料“备注”里建议回避的内容都没有使用。
- 节点数据由项目外的生成脚本 `build_celebs.py` 生成（真名 → 名称键替换、残留拉丁词与黑名单检查、游戏机制配置），
  同时生成 `test/banned-generated.json`（资料中出现的全部真实人名/机构名，用于扫描）。
- 效果数值（估值、持股、名气等）是游戏化简化，不代表真实数据。

## 城市、音乐与氛围
- 13 座城市各有独立大地图（布局放大 3 倍，分成商务、滨水、住宅等城区，镜头跟着人走，右上角小地图标出自己和本章目标；`js/data/cities.js` 末尾的 `LAYOUTS`）：尺寸、道路网格、水域类型（海岸在下 / 海岸在右 / 河流横穿 + 桥）、
  街区里建筑的位置都不同；9 类建筑由 `js/engine/map.js` 自动摆进街区，门朝道路，保证可达（测试会做 BFS 校验）。
- 像素地标（通用造型、无商标）：硅谷 大学钟楼/传奇车库，洛杉矶 海滨摩天轮/棕榈大道，纽约 摩天楼群/火炬女神像，西雅图 飞碟观景塔/海鲜市场，
  上海 明珠电视塔/外滩老建筑群，台北 百层大楼/夜市，东京 红色电视塔/神社鸟居，杭州 湖畔古塔/断桥，伦敦 议会大钟/河畔观景轮，
  曼彻斯特 红魔球场/红砖仓库，马德里 白色球场/王宫，芝加哥 镜面豆子雕塑/湖滨天际线，华盛顿 国会圆顶/纪念方尖碑。走到地标前按 E 可“拍照打卡”。
- `js/engine/audio.js`：Web Audio 程序生成的芯片音乐，每城一首（速度、调式、音色不同），外加音效。
  M 键或「🔊 声音」按钮静音，设置保存在 localStorage（`yxrs_mute`）。浏览器要求先有一次点击/按键才会出声。
- 昼夜循环（约 4 分钟一轮，纯视觉）：黄昏、夜晚窗户亮灯、路灯和车灯光晕；N 键或菜单开关（`yxrs_daynight`）。

## 名称（全部为戏仿名）
游戏中不出现真实人名、公司名、产品名。所有名称集中在 `js/data/names.js`：数据文件里写 `{键名}`，显示时由 `YXRS.t()` 替换为戏仿名。
改名只需改这一个文件。`node test/no-real-names.js` 会扫描所有游戏文件，发现真实名称即报错。

## 新增名人
1. 准备一份同格式的研究资料（JSON），在生成脚本里加一段配置（节点标题、需要删减的内容、游戏机制），运行生成脚本；
   或者手写一个 `js/data/celebs/<id>.js`，结构：`bio / look / starts / nodes（含 basis 史实依据）/ contacts / projects / history`。
2. 在 `index.html` 里名人数据那一行下面加一个 `<script>`。
新城市：在 `js/data/cities.js` 里 `C({...})` 注册并在 `LAYOUTS` 加布局即可，机场会自动出现。

## 文件
- `index.html`、`css/style.css`
- `js/core.js` 注册表与工具
- `js/data/cities.js` 城市；`js/data/investments.js` 投资机会+通用项目；`js/data/events.js` 时代/随机事件
- `js/data/names.js` 名称表（唯一出处）
- `js/data/celebs/*.js` 8 位名人数据（rocketman、gpuboss、softking、tower、merchant、freekick、senator、visionary）
- `js/engine/sprites.js` 程序化像素人物/车辆；`js/engine/map.js` 每城地图生成、地标绘制；`js/engine/audio.js` 音乐与音效
- `js/game.js` 主逻辑（状态、时间、效果、对话、HUD、存档 localStorage）
- 测试（需 `npm i playwright-core` 和本机 Chrome）：
  `test/no-real-names.js` 真实名称扫描；`test/smoke.js` 冒烟测试（含页面文字扫描）；`test/cities.js` 走遍全部城市；
  `test/playall.js` 8 位名人 × 3 个开局 × 3 种玩法（全史实/全备选/随机）都能玩到结局；`test/balance.js` 数值跑局。

人物经历依据公开资料整理，人名与公司名为戏仿名，数值为游戏化简化，仅供娱乐。
